# Retail Sales Analytics Using Databricks

## Project Overview
This project analyzes retail sales data using Databricks to identify business insights, sales trends, regional performance, and top-performing products.

## Tools and Technologies
- Databricks Unity Catalog
- SQL
- Databricks Genie
- Databricks AI/BI Dashboards

## Dataset Overview
- Total records: 1,000
- Distinct products: 100
- Total quantity sold: 25,355 units
- Total revenue: 5,019,265.23

## Project Activities
- Explored the sales dataset using Unity Catalog.
- Analyzed overall sales performance using SQL.
- Compared revenue across regions and product categories.
- Identified monthly sales trends.
- Analyzed the top five products by revenue.
- Used Databricks Genie to explore business questions.
- Created an interactive AI/BI dashboard with KPI cards, charts, and filters.

## Key Business Insights
- The North region generated the highest revenue.
- Clothing was the highest-revenue product category.
- Product ID 1099 ranked first among the top five products by revenue.
- Monthly revenue varied throughout the available period.
